外掛是 .moss/plugins// 中的 JavaScript 套件。它們接入編譯流程的五個階段——轉換內容、注入範本插槽、部署、分發。

每個外掛有一個描述其能力和設定的 manifest。

.moss/plugins/my-plugin/
├── manifest.json
├── main.bundle.js
└── icon.svg

命令列

用於測試和自動化的命令列介面。

插槽

範本注入點與增強階段。

外掛清單參考、設定和 moss-api SDK。
