自訂設計只需要兩個檔案，都可選，都放在專案的 `.moss/theme/` 目錄裡（青苔在你開啟資料夾時會自動建立它）：

- **`.moss/theme/style.css`**——覆蓋顏色、字型、間距和元件樣式。
- **`.moss/theme/script.js`**——加入自訂互動。

```
my-site/
├── .moss/
│   └── theme/
│       ├── style.css   ← 自訂 CSS
│       └── script.js   ← 自訂 JS
├── index.md
└── ...
```

不需要建置步驟，不需要設定。青苔會自動載入這兩個檔案：`style.css` 排在預設主題之後、層疊順序最靠後的 `themes` 層，你的規則自然勝出，無需寫 `!important`；`script.js` 在所有內建指令碼之後執行，此時 DOM 已就緒。

## 用變數調整外觀

青苔的樣式建立在一套 `--moss-*` CSS 變數上。覆蓋幾個變數就能換掉整體觀感：

```css
:root {
  --moss-color-accent: #2d5a2d;      /* 連結與強調色 */
  --moss-font-body: "Inter", sans-serif;
  --moss-content-width: 72ch;        /* 內文最大寬度 */
}
```

深色模式只需覆蓋一個選擇器，青苔已經把系統偏好和手動切換都歸到 `data-theme` 上：

```css
:root[data-theme="dark"] {
  --moss-color-bg: #0f0f0f;
  --moss-color-accent: #6abf6a;
}
```

執行 `moss describe --json` 可列出全部變數及其亮色／暗色預設值。

## 針對元件微調

青苔生成的每個元件都有穩定的 `.moss-*` class 名稱，可以在 `style.css` 裡直接定位，例如 `.moss-grid-card`、`.moss-collection-card`、`.callout`。也可以給短代碼掛自訂 class：`:::grid 3 {.profiles}`，再寫 `.profiles .moss-grid-card { … }`。

> [!tip] 版面寫進 class 裡，別寫進短代碼
> 需要響應式列寬時，用 `:::grid 2 {.two-col}` 不帶比例，在 CSS 裡定義 `grid-template-columns`。寫進短代碼的比例會輸出內聯樣式，壓過 `@media` 規則。

## 其他資源

字型等靜態檔案也放進 `.moss/theme/`：把 `.woff2` 放在 `.moss/theme/fonts/`，在 `style.css` 中用 `@font-face { src: url('fonts/myfont.woff2') }` 引用。整個 `.moss/theme/` 目錄作為網站根目錄的兄弟目錄對外提供。
