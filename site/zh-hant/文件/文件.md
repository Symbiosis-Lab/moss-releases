青苔將你資料夾中的 markdown 檔案與其他媒體打包成為網站。你可以使用任何 markdown 編輯器，比如 [Obsidian](https://obsidian.md/zh/)，也可以使用青苔自帶編輯器，書寫文字、加入其他素材。

## 發佈網站

建立一個資料夾，以網站名稱命名。右鍵選單中選擇「發佈」，在編輯器中建立新檔案，開始寫作。青苔會即時預覽生成的網站。
%% start from empty folder, create new file, and edit. %%
![[folder-to-site.html]]

青苔將每一個資料夾與 markdown 檔案變成一個頁面。資料夾頁面預設渲染其中子檔案與資料夾，你可以將其關閉，或選擇不同的樣式。
%% create  %%
![[folder-to-site.html]]

網站成型後，在預覽視窗中再次點擊發佈，網站上線。初次發佈，為網站選擇免費 mosspub.com 子網域。
%% 发布 -> 子域名 -> live site -> view in browser %%
![[folder-to-site.html]]

你可以在任何時候點擊網站圖示右上角選單，進入設定，購買獨立網域。購買後，青苔會自動為你配置好網域及 CDN（內容分發網路）。
%% purchase independent domain %%
![[folder-to-site.html]]

## 郵件列表

你可以啟用郵件列表，讓讀者透過電郵訂閱你的作品。

點擊「+」，新增郵件管道，訂閱入口將自動出現在網站頁尾。當你完成一篇新文章時，勾選郵件管道，青苔會在部署網站之後打開郵件編輯器，讓你預覽和確認。

![[folder-to-site.html]]
