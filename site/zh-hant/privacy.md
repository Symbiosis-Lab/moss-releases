# 隱私

青苔是 **共生實驗室** 打造的本地優先發佈工具。一句話概括：**你的文字始終留在你自己的電腦上**，我們盡可能少地收集資料，**沒有廣告，也不做使用情況追蹤**。

這是一份早期的隱私說明——青苔仍在積極開發中——我們會隨產品成長而不斷完善。如有不清楚之處，歡迎[聯絡我們](#contact)。

## 你的內容屬於你

你的 Markdown 資料夾及其中的一切都保存在**你自己的裝置上**。只有當**你主動選擇發佈**時，內容才會離開你的電腦——而且離開的只是最終生成的網站，託管在我們的伺服器上並按你的意願公開展示。

## 你的帳戶

為了發佈或訂閱，我們會使用你的**電子郵件**和你裝置的**公鑰**（一個加密識別碼——沒有密碼）。我們將其保存在自己的伺服器上，以便辨識哪些網站屬於你。

## 付款

付款（網站訂閱與網域購買）由位於美國的支付處理商 **Stripe** 處理。**信用卡資訊由 Stripe 保管——我們從不接觸你的卡號。** 我們僅保留你的 Stripe 客戶 ID 與電子郵件以管理訂閱；收據由 Stripe 寄送。

## 自訂網域

如果你透過青苔**註冊網域**，網域註冊商（位於加拿大的 **OpenSRS / Tucows**）需要 ICANN 聯絡資訊——你的姓名、地址、電話與國家/地區。我們會開啟 **WHOIS 隱私保護**，使這些資訊不被公開，並且**我們自己不儲存它們**（只保留網域與你的電子郵件）。如果你**連結一個已經擁有的網域**，則不會額外收集任何資訊。

## 電子報（如果你開啟了的話）

如果你的網站有電子報，**讀者訂閱時填寫的電子郵件**會為你的網站保存在我們的伺服器上，郵件透過 **Resend**（位於美國的郵件服務）寄送。我們採用確認式訂閱（double opt‑in），**不儲存讀者的 IP 位址**。身為站長，讀者的資料由你負責——我們只是代你保管，方便你向他們寄信。

## 留言（如果你啟用了的話）

當有人在你發佈的網站上留言時，其**暱稱**（以及選填的電子郵件與網址）、留言內容，以及基本的技術資訊——**IP 位址與瀏覽器**——會保存在我們**自架的留言系統**中（而非第三方），這是留言系統的常規做法。如啟用了回覆通知，通知將透過 Resend 寄送。

## 網站流量統計

對於已發佈的網站，我們保留**基礎的、彙總的流量統計**——國家/地區、瀏覽器、作業系統，以及被瀏覽的頁面。這些統計中**不含 Cookie、不做跨站追蹤、不含 IP 位址**。（我們伺服器的原始存取紀錄可能會包含訪客 IP，用於安全與維運，不會用於追蹤任何人。）

## 當機回報

如果青苔遇到錯誤，它可以向我們自己的伺服器傳送一份**當機報告**，協助我們修復問題——這是青苔唯一自動回報的內容，**不會追蹤你如何使用應用程式**。我們會剝除個人資料：**不儲存你的 IP**（在到達我們的錯誤追蹤系統前已被遮罩），檔案路徑也會被清理。你可以隨時在 **青苔 → 設定 → 當機回報** 中關閉它，當機報告會在 **90 天**後刪除。

## 支援紀錄

如果你使用**「傳送紀錄」**來回報問題，青苔會上傳你最近的應用程式紀錄（已清理個人資料）以及你填寫的備註——但僅在**你主動發起**時。這些紀錄會在 **30 天**後刪除。

## 資料在哪裡處理

我們的伺服器位於**美國**，我們依賴的部分服務（Stripe、Resend、Cloudflare）也在美國；我們的網域註冊商（OpenSRS / Tucows）位於**加拿大**。如果你身處歐盟或英國，你的資料可能會在你所在國家/地區以外處理。

## 我們保留多久

當機報告：90 天。支援紀錄：30 天。你的帳戶、付款與訂閱者紀錄會在你的帳戶或網站有效期間保留。想刪除你的資料？告訴我們一聲即可。

## 你的選擇與權利

你可以要求我們**查看、更正或刪除**你的資料，也可以隨時透過應用程式內的開關**拒絕當機回報**。當機回報我們依據的是維持青苔穩定可靠的**正當利益**（而非同意）；帳戶與付款則依據我們與你之間的協議。
