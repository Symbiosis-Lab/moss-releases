短代碼是寫在 markdown 裡的特殊區塊，用 `:::` 圍欄語法建立標準 markdown 沒有的版面與元件。青苔會為每個短代碼產生固定的類名，預設主題已經配好樣式。

## 多欄網格

`:::grid N` 把內容排成 N 欄，儲存格之間用 `+++` 分隔。儲存格裡可以放任何 markdown——文字、圖片、連結、卡片。

:::grid 2 {.sc-demo}
```markdown
:::grid 2
左欄內容
+++
右欄內容
:::
```
+++
::::grid 2
左欄內容
+++
右欄內容
::::
:::

在欄數後加 `a:b` 比例可設定各欄寬度，如 `:::grid 2 1:2`。只把一個內部連結單獨放進一格，青苔會把它渲染成帶封面的卡片。

## 標註

用 `> [!類型]` 開頭的引用區塊突顯重要內容，類型有 `note`、`tip`、`warning`、`pending` 等。

:::grid 2 {.sc-demo}
```markdown
> [!note] 提示
> 這裡是需要讀者留意的內容。
```
+++
> [!note] 提示
> 這裡是需要讀者留意的內容。
:::

## 其他常用短代碼

| 短代碼 | 用途 |
|--------|------|
| `::::buttons` | 一排按鈕，每個是一個連結 |
| `:::hero` | 鋪滿寬度的大圖，文字疊加其上 |
| `:::gallery` | 圖片畫廊 |
| `::: {.類名}` | 給一段內容附加 CSS 類，無需新短代碼 |

最後一種「命名類圍欄」最靈活：`::: {.eyebrow}` 之類給區塊掛上類名，再在 [[設計與主題|主題的 style.css]] 裡寫樣式即可，不必等待新的短代碼。
