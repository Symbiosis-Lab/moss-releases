青苔將你資料夾中的 markdown 檔案與其他媒體打包成為網站。你可以使用任何 markdown 編輯器，比如 [Obsidian](https://obsidian.md/zh/)，也可以使用青苔自帶編輯器，書寫文字、加入其他素材。

## 發佈網站

[下載並安裝青苔](https://github.com/Symbiosis-Lab/moss-releases/releases/latest/download/moss.dmg)（目前只支援 mac）。建立一個資料夾，以網站名稱命名。右鍵選單中選擇「發佈」，啟動青苔預覽。青苔自動打開編輯器，你可以建立新檔案，開始寫作。

右手邊預覽視窗，你的網站已經生成好了，預設支援明暗風格。向左拖曳分割線，關閉編輯器，預覽生成的網站。

![[new folder.gif]]

* 你可以在編輯器中建立新資料夾和新檔案，每一個資料夾與 markdown 檔案都會變成一個頁面，自動生成頂部導覽。
* 你可以從其他資料夾中拖入圖片、影片、音訊、notebook 甚至網頁，內嵌到網頁中。
* 資料夾頁面預設渲染其中子檔案與資料夾。主頁預設渲染所有子檔案。
* 你可以點擊「+」號設定頁面封面圖、日期、子頁面風格。

![[editing.gif]]

網站成型後，在預覽視窗中再次點擊發佈，網站上線。初次發佈，認證郵箱，並為網站選擇免費 mosspub.com 子網域。
![[first time publish.gif]]

你可以在任何時候點擊網站圖示右上角選單，進入設定，購買獨立網域。購買後，青苔會自動為你配置好網域及 CDN（內容分發網路）。
![[custom domain.gif]]


## 郵件列表

你可以啟用郵件列表，讓讀者透過電郵訂閱你的作品。

點擊「+」，新增郵件管道，訂閱入口將自動出現在網站頁尾。當你完成一篇新文章時，勾選郵件管道，青苔會在部署網站之後打開郵件編輯器，讓你預覽和確認。
![[email sub.gif]]



## 接下來

青苔編輯器有直觀的介面：選取文字顯示工具，輸入`/`觸發常用功能，點擊編輯器上方 `+` 或者 `+N` 修改頁面屬性。你可以直接玩玩看，不需要了解青苔使用的具體規則。但如果你想進一步了解如何透過青苔建站，可以參考以下文件。
