# 參考

建構 moss 佈景與外掛時的契約：確切的欄位名、類別名與命令。本節的參考內容以英文版為準，中文譯文陸續更新。

- [[frontmatter|Frontmatter]]——每個頁面的中繼資料欄位。
- [[cli|命令列]]——moss 命令與參數。
- [[manifest|Manifest]] · [[hooks|Hooks]] · [[slots|Slots]]——外掛契約。

執行 `moss describe --json` 可取得你所安裝版本的即時設計權杖、元件類別名與 frontmatter 欄位。
