# 給你的網站一個網址

> 想讓網站用你自己的名字，例如 yourname.com？在 moss 裡就能找到、買下、連好，全程不用離開。

你的網站已經在線上了。這個頁面會給它一個你自己的網址，讓大家用你挑的名字找到它，而不是一串較長的預設網址。moss 會幫你找名字、買下來，並替你設定好。

買網址需要 moss 付費方案。如果你還沒有，當你動手買的時候 moss 會提醒你。

## 找一個名字

**1. 開啟設定。** 在設定裡開啟**部署**分頁，你會看到一列**網域**。

**2. 搜尋。** 點一下**網域**輸入框（上面寫著**搜尋網域**），輸入你想要的名字。會展開一個清單，分成**你的網域**、**完全符合**、**可購買**和**已被註冊**幾組。可以買的名字會標出價格，已經有人擁有的名字會標示**已被註冊**。

**3. 挑一個。** 點一個還能買的名字，它正下方會展開一段簡短的結帳流程。

如果你以前已經透過 moss 買過網址，頁尾連結**已經購買過網域？驗證你的電子郵件即可查看。**會把它找回來。先驗證你的電子郵件，它就會出現在**你的網域**底下。

## 買下來

你需要一個已驗證的電子郵件。如果你還沒驗證，moss 會顯示**購買網域前，請先驗證上方的電子郵件。**先在上方那一列驗證電子郵件，再回來這裡。

**1. 填寫你的資料。** 輸入**國家/地區**、**姓名**、**電話**和**街道地址**。在美國以外，你還要填**城市**。moss 會說明原因：**ICANN 要求提供準確的聯絡資訊以保持您的網域有效。我們使用聯絡資訊隱私保護使其不出現在公開 WHOIS 中。**你的資料只會留在私下，不會公開。

**2. 加一張卡。** 輸入你的信用卡。moss 提醒：**您的信用卡將被儲存，用於未來的續訂與購買。您可以隨時更換。**

**3. 購買。** 點下按鈕，上面寫著**購買**加上價格。處理時會顯示**處理中…**。想中止就點**取消**。

## 看著它上線

買完之後，moss 會替你把一切設定好，並在**網域**輸入框下方顯示一個面板。最上面寫著「正在設定 HOST · 通常幾分鐘內就緒」（HOST 就是你的新網址）。下面有幾個步驟，會從等待逐一變成完成：

- 網域註冊
- HOST 的公開 DNS
- HOST 的憑證
- 網站可在 HOST 連上

這通常只要幾分鐘。moss 會自己持續查看。一切就緒後，面板會顯示「HOST 已上線」，並出現一個「造訪 HOST」按鈕。點它就能用新網址開啟你的網站。

如果比較慢，moss 可能會說「比平常久一些」並繼續嘗試。它也會提醒：「如果你的網路顯示的是舊版本，可能要幾分鐘才會更新。」如果有哪一步沒能完成，你會看到「無法連上 HOST」，可以用「重新檢查」再試一次，或用「忽略」關掉面板。如果你的連線中斷，moss 會顯示「你的網路似乎離線了。等它恢復我們會繼續嘗試。」並在恢復後自己接著做。

一旦你的網站在新網址上線，**網域**那一列會顯示**已上線**以及多久之前，還可能提到你的舊網址仍會重新導向到這裡，所以舊連結照樣有效。
