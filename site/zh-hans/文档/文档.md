青苔将你文件夹中的 markdown 文件与其他媒体打包成为网站。你可以使用任何 markdown 编辑器，比如 [Obsidian](https://obsidian.md/zh/)，也可以使用青苔自带编辑器，书写文字、加入其他素材。

## 发布网站

创建一个文件夹，以网站名称命名。右键菜单中选择「发布」，在编辑器中创建新文件，开始写作。青苔会及时预览生成的网站。
%% start from empty folder, create new file, and edit. %%
![[folder-to-site.html]]

青苔将每一个文件夹与 markdown 文件变成一个页面。文件夹页面默认渲染其中子文件与文件夹，你可以将其关闭，或选择不同的样式。
%% create  %%
![[folder-to-site.html]]

网站成型后，在预览窗口中再次点击发布，网站上线。初次发布，为网站选择免费 mosspub.com 子域名。
%% 发布 -> 子域名 -> live site -> view in browser %%
![[folder-to-site.html]]

你可以在任何时候点击网站图标右上角菜单，进入设置，购买独立域名。购买后，青苔会自动为你配置好域名及 CDN（内容分发网络）。
%% purchase independent domain %%
![[folder-to-site.html]]

## 邮件列表

你可以启用邮件列表，让读者通过邮箱订阅你的作品。

点击“+”，添加邮件渠道，订阅入口将自动出现在网站页脚。当你完成一篇新文章时，勾选邮件渠道，青苔会在部署网站之后打开邮件编辑器，让你预览和确认。

![[folder-to-site.html]]
