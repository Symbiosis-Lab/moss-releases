自定义设计只需要两个文件，都可选，都放在项目的 `.moss/theme/` 目录里（青苔在你打开文件夹时会自动创建它）：

- **`.moss/theme/style.css`**——覆盖颜色、字体、间距和组件样式。
- **`.moss/theme/script.js`**——添加自定义交互。

```
my-site/
├── .moss/
│   └── theme/
│       ├── style.css   ← 自定义 CSS
│       └── script.js   ← 自定义 JS
├── index.md
└── ...
```

不需要构建步骤，不需要配置。青苔会自动加载这两个文件：`style.css` 排在默认主题之后、层叠顺序最靠后的 `themes` 层，你的规则自然胜出，无需写 `!important`；`script.js` 在所有内置脚本之后运行，此时 DOM 已就绪。

## 用变量调整外观

青苔的样式建立在一套 `--moss-*` CSS 变量上。覆盖几个变量就能换掉整体观感：

```css
:root {
  --moss-color-accent: #2d5a2d;      /* 链接与强调色 */
  --moss-font-body: "Inter", sans-serif;
  --moss-content-width: 72ch;        /* 正文最大宽度 */
}
```

深色模式只需覆盖一个选择器，青苔已经把系统偏好和手动切换都归到 `data-theme` 上：

```css
:root[data-theme="dark"] {
  --moss-color-bg: #0f0f0f;
  --moss-color-accent: #6abf6a;
}
```

运行 `moss describe --json` 可列出全部变量及其亮色/暗色默认值。

## 针对组件微调

青苔生成的每个组件都有稳定的 `.moss-*` 类名，可以在 `style.css` 里直接定位，例如 `.moss-grid-card`、`.moss-collection-card`、`.callout`。也可以给短代码挂自定义类：`:::grid 3 {.profiles}`，再写 `.profiles .moss-grid-card { … }`。

> [!tip] 布局写进类里，别写进短代码
> 需要响应式列宽时，用 `:::grid 2 {.two-col}` 不带比例，在 CSS 里定义 `grid-template-columns`。写进短代码的比例会输出内联样式，压过 `@media` 规则。

## 其他资源

字体等静态文件也放进 `.moss/theme/`：把 `.woff2` 放在 `.moss/theme/fonts/`，在 `style.css` 中用 `@font-face { src: url('fonts/myfont.woff2') }` 引用。整个 `.moss/theme/` 目录作为站点根目录的兄弟目录对外提供。
