# 隐私

青苔是 **共生实验室** 打造的本地优先发布工具。一句话概括：**你的文字始终留在你自己的电脑上**，我们尽可能少地收集数据，**没有广告，也不做使用情况追踪**。

这是一份早期的隐私说明——青苔仍在积极开发中——我们会随产品成长而不断完善。如有不清楚的地方，欢迎[联系我们](#contact)。

## 你的内容属于你

你的 Markdown 文件夹及其中的一切都保存在**你自己的设备上**。只有当**你主动选择发布**时，内容才会离开你的电脑——而且离开的只是最终生成的网站，托管在我们的服务器上并按你的意愿公开展示。

## 你的账户

为了发布或订阅，我们会使用你的**电子邮箱**和你设备的**公钥**（一个加密标识——没有密码）。我们将其保存在自己的服务器上，以便识别哪些网站属于你。

## 付款

付款（网站订阅和域名购买）由位于美国的支付处理商 **Stripe** 处理。**银行卡信息由 Stripe 保管——我们从不接触你的卡号。** 我们仅保留你的 Stripe 客户 ID 和邮箱以管理订阅；收据由 Stripe 发送。

## 自定义域名

如果你通过青苔**注册域名**，域名注册商（位于加拿大的 **OpenSRS / Tucows**）需要 ICANN 联系信息——你的姓名、地址、电话和国家/地区。我们会开启 **WHOIS 隐私保护**，使这些信息不被公开，并且**我们自己不存储它们**（只保留域名和你的邮箱）。如果你**关联一个已经拥有的域名**，则不会额外收集任何信息。

## 邮件订阅（如果你开启了的话）

如果你的网站有邮件订阅，**读者订阅时填写的邮箱地址**会为你的网站保存在我们的服务器上，邮件通过 **Resend**（位于美国的邮件服务）发送。我们采用确认式订阅（double opt‑in），**不存储读者的 IP 地址**。作为站长，读者的数据由你负责——我们只是代你保管，方便你向他们发送邮件。

## 评论（如果你启用了的话）

当有人在你发布的网站上评论时，其**昵称**（以及可选的邮箱和网址）、评论内容，以及基本的技术信息——**IP 地址和浏览器**——会保存在我们**自托管的评论系统**中（而非第三方），这是评论系统的常规做法。如启用了回复通知，通知将通过 Resend 发送。

## 网站访问统计

对于已发布的网站，我们保留**基础的、聚合的访问统计**——国家/地区、浏览器、操作系统，以及被访问的页面。这些统计中**不含 Cookie、不做跨站追踪、不含 IP 地址**。（我们服务器的原始访问日志可能会包含访客 IP，用于安全与运维，不会用于追踪任何人。）

## 崩溃报告

如果青苔遇到错误，它可以向我们自己的服务器发送一份**崩溃报告**，帮助我们修复问题——这是青苔唯一自动上报的内容，**不会追踪你如何使用应用**。我们会剥离个人数据：**不存储你的 IP**（在到达我们的错误跟踪系统前已被屏蔽），文件路径也会被清理。你可以随时在 **青苔 → 设置 → 崩溃报告** 中关闭它，崩溃报告会在 **90 天**后删除。

## 支持日志

如果你使用**“发送日志”**来反馈问题，青苔会上传你最近的应用日志（已清理个人数据）以及你填写的备注——但仅在**你主动发起**时。这些日志会在 **30 天**后删除。

## 数据在哪里处理

我们的服务器位于**美国**，我们依赖的部分服务（Stripe、Resend、Cloudflare）也在美国；我们的域名注册商（OpenSRS / Tucows）位于**加拿大**。如果你身处欧盟或英国，你的数据可能会在你所在国家/地区以外处理。

## 我们保留多久

崩溃报告：90 天。支持日志：30 天。你的账户、付款和订阅者记录会在你的账户或网站有效期间保留。想删除你的数据？告诉我们一声即可。

## 你的选择与权利

你可以要求我们**查看、更正或删除**你的数据，也可以随时通过应用内的开关**拒绝崩溃报告**。崩溃报告我们依据的是维持青苔稳定可靠的**正当利益**（而非同意）；账户与付款则依据我们与你之间的协议。
