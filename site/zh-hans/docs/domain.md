# 给你的网站一个网址

> 想让网站用上你自己的名字，比如 yourname.com 吗？不用离开 moss，就能搜索、购买并连接它。

你的网站已经在线上了。这个页面会给它一个你自己的网址，让别人用你选定的名字访问，而不是更长的默认地址。moss 会帮你搜索名字、购买它，并替你完成设置。

购买网址需要 moss 付费方案。如果你还没有，尝试购买时 moss 会提示你。

## 搜索一个名字

**1. 打开设置。** 在设置里打开**部署**标签页，你会看到一行**域名**。

**2. 搜索。** 点击**域名**输入框（里面写着**搜索域名**），输入你想要的名字。会弹出一个列表，分成**你的域名**、**完全匹配**、**可购买**和**已被注册**几组。可以购买的名字会显示价格，已经有人拥有的名字会标记为**已被注册**。

**3. 选一个。** 点击一个可用的名字，它正下方会展开一个简短的结账流程。

如果你之前已经通过 moss 买过网址，页脚的链接**已经购买过域名？验证你的电子邮件即可查看。**可以把它找回来。先验证你的电子邮件，它就会出现在**你的域名**下。

## 购买它

你需要一个已验证的电子邮件。如果还没验证，moss 会提示**购买域名前，请先验证上方的电子邮件。**先在上面那一行验证电子邮件，然后再回来。

**1. 填写你的信息。** 输入**国家/地区**、**姓名**、**电话**和**街道地址**。在美国以外，你还要填一个**城市**。moss 会解释原因：**ICANN 要求提供准确的联系信息以保持您的域名有效。我们使用联系信息隐私保护使其不出现在公开 WHOIS 中。**你的信息会保持私密，不会公开。

**2. 添加一张银行卡。** 输入你的银行卡。moss 会注明：**您的银行卡将被保存，用于未来的续费和购买。您可以随时更换。**

**3. 购买。** 点击按钮，上面会显示**购买**加上价格。处理过程中它会显示**处理中…**。想停下来，点击**取消**。

## 看着它上线

购买后，moss 会替你完成所有设置，并在**域名**输入框下方显示一个面板。面板顶部写着 **正在设置 HOST · 通常几分钟内就绪**（HOST 是你的新网址）。下方有几个步骤会从等待变成完成：

- 注册域名
- 为 HOST 解析公共 DNS
- 为 HOST 签发证书
- 网站可在 HOST 访问

这通常需要几分钟。moss 会自己持续检查。一切就绪后，面板会显示 **HOST 已上线**，并出现一个**访问 HOST** 按钮，点击它即可用新网址打开你的网站。

如果慢了，moss 可能会提示**用时比平常长**并继续尝试。它还会注明：如果你的网络显示的是旧版本，可能需要几分钟才会更新。如果某一步没能完成，你会看到**无法连接 HOST**，可以点击**重新检查**再试一次，或点击**关闭**收起面板。如果你的网络断了，moss 会提示网络似乎已离线，恢复后它会继续尝试，并自行接着进行。

网站在新网址上线后，**域名**那一行会显示**已上线**以及多久之前完成，并可能注明你的旧网址仍会重定向到这里，让旧链接继续有效。
