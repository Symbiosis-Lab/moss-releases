# 从 Matters 导入

> 已经在 Matters 上写作？把文章带过来，moss 会把它们变成真正属于你的网站。

你在 Matters 上的写作，会变成你自己的网站。你只需添加一次 Matters、登录，moss 就会把文章复制过来：封面图、文中插图，连评论数和点赞数也一并带上。然后它把这些内容变成你的网站，准备好发布到线上。Matters 上的任何东西都不会改变。

## 添加 Matters

**1. 打开渠道列表。** 主窗口右上角有一个小小的 **+** 按钮。把鼠标悬停上去，会看到“添加渠道”。点击它。moss 会打开设置并停在**渠道**标签页，这里集中着你可以分享写作的各个去处。

**2. 添加 Matters。** 找到 **Matters** 图标。悬停时会出现提示“**Matters（点击添加）**”。点击它，提示会翻成“**Matters（点击移除）**”，表示已经添加成功。（在你添加之前，Matters 不会出现在那里。）

## 登录

添加 Matters 后，moss 会立刻在一个小窗口里打开真正的 Matters 登录页面。按你平时的方式登录就好。

接下来是有点让人意外的一步：登录之后，窗口会静止大约二十秒，看上去什么也没做。**这是正常的。** moss 在等待，然后替你检查，一旦确认登录成功，它会自己关掉窗口。你什么都不用点。

## 文章进来了

moss 开始复制你的文章，写作区附近会出现一条细细的进度线，显示进展。窗口底部没有进度条，请留意标题旁边的那条进度。

复制时，文章会逐篇下载，画面上方靠近标题处会显示进度：先获取文章列表，再统计要同步的篇数，然后逐篇同步每一篇文章。最长的一段是下载图片。你的文章会一篇接一篇地到达，每篇都带着封面图和文中的插图，以及它原有的评论数和点赞数。

如果你在 Matters 上用中文写作，文章会落在一个名为 **文章** 的文件夹里；否则落在 **articles** 里。

有几点需要知道：

- 第一次会花些时间，因为 moss 要把所有内容都带进来。之后它只检查有什么是新增或改动的，所以后续的同步都很快。
- 草稿留在 Matters。moss 只带进你已发布的文章，不带未完成的。

## 网站逐渐成形

文章陆续到达时，moss 会把它们变成一个网站，并在右侧窗格中显示出来。这个预览只给你自己看。目前还没有任何内容上线，所以随便逛逛、好好读一读。

## 发布到线上

**1. 按下发布。** 右上角有一个圆形按钮。悬停时会看到**发布**。点击它，moss 会打开一段简短的设置，标题是**设置你的站点**。

**2. 选好网址，填入邮箱。** moss 会建议一个以 `.mosspub.com` 结尾的网址，比如 `my-blog`，你可以保留或修改。它会检查并显示**可用**或**不可用**。在**邮箱**下填入你的邮箱，然后选择**验证邮箱**。

**3. 点击邮件里的链接。** moss 会显示**检查你的邮箱**并等待，同时显示**等待验证…**。打开它发来的邮件，点击其中的链接。moss 会自己察觉并继续往下走。（如果你以前用这个邮箱发布过，moss 会跳过这一步，按钮直接显示为**发布**。）如果邮件没有到，用**重新发送**，或者用**更改邮箱**换一个试试。

**4. 已经上线。** moss 会显示**正在设置你的站点…**，接着是**已发布。**，并附上一行**你的站点已上线**和你的网址。点击**访问站点**去看看，或者点**稍后**继续写作。

整件事就是这样。你在 Matters 上的写作，现在已经是一个属于你的网站了。任何时候，只要你改动了某篇文章，或者想把 Matters 上最新的文章带过来，再按一次**发布**，你的网站就会更新。
