# 参考

构建 moss 主题与插件时的契约：确切的字段名、类名和命令。本节的参考内容以英文版为准，中文译文陆续更新。

- [[frontmatter|Frontmatter]]——每个页面的元数据字段。
- [[cli|命令行]]——moss 命令与参数。
- [[manifest|Manifest]] · [[hooks|Hooks]] · [[slots|Slots]]——插件契约。

运行 `moss describe --json` 可获取你所安装版本的实时设计令牌、组件类名与 frontmatter 字段。
