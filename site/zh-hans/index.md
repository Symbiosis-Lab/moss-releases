# 随处写作，随处发布。一切由你掌控。

把文件夹打包成独立网站。右键，预览，发布。

:::buttons
[申请测试版](#青苔正在封闭测试)
[文档](docs/)
:::

:::grid 3
**本地写作**

Markdown 文件。使用内置编辑器、Obsidian、或者任意其他软件。
+++
**右键发布**

预览、确认、发布。同步到各平台。
+++
**独立网站**

选择托管服务。购买域名，或者使用默认域名。
:::

## 开放格式，本地优先

内容存于你的计算机中，用你的操作系统管理内容，用共享文件夹多人协作。网站从本地计算机部署到服务器，零成本迁移。

## 通用方案，多种渠道

标准静态网页，部署在任何服务器。内容发表到独立网站，同时同步到各个平台，再同步回评论。

## 多种媒体，自动处理

视频、图片、HTML、Jupyter Notebook。放进文件夹，青苔处理其余一切。

## 无限扩展

通过 CSS 和 JavaScript 自定义设计，通过脚本插件自定义编译流程。尽情 vibe code，青苔让你的网站可读、可维护。
