短代码是写在 markdown 里的特殊块，用 `:::` 围栏语法创建标准 markdown 没有的布局与组件。青苔为每个短代码生成固定的类名，默认主题已经配好样式。

## 多栏网格

`:::grid N` 把内容排成 N 栏，单元格之间用 `+++` 分隔。单元格里可以放任何 markdown——文字、图片、链接、卡片。

:::grid 2 {.sc-demo}
```markdown
:::grid 2
左栏内容
+++
右栏内容
:::
```
+++
::::grid 2
左栏内容
+++
右栏内容
::::
:::

在栏数后加 `a:b` 比例可设置各栏宽度，如 `:::grid 2 1:2`。只把一个内部链接单独放进一格，青苔会把它渲染成带封面的卡片。

## 标注

用 `> [!类型]` 开头的引用块突出重要内容，类型有 `note`、`tip`、`warning`、`pending` 等。

:::grid 2 {.sc-demo}
```markdown
> [!note] 提示
> 这里是需要读者留意的内容。
```
+++
> [!note] 提示
> 这里是需要读者留意的内容。
:::

## 其他常用短代码

| 短代码 | 用途 |
|--------|------|
| `::::buttons` | 一排按钮，每个是一个链接 |
| `:::hero` | 铺满宽度的大图，文字叠加其上 |
| `:::gallery` | 图片画廊 |
| `::: {.类名}` | 给一段内容附加 CSS 类，无需新短代码 |

最后一种「命名类围栏」最灵活：`::: {.eyebrow}` 之类给区块挂上类名，再在 [[设计与主题|主题的 style.css]] 里写样式即可，不必等待新的短代码。
