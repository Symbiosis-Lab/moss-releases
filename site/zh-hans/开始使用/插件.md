插件就是放在 `.moss/plugins/{名称}/` 里的一个 JavaScript 包。青苔会自动发现它，读取它的清单，在每次构建的合适阶段调用它声明的钩子。

```
.moss/plugins/my-plugin/
├── manifest.json     ← 描述插件的能力与配置
├── main.bundle.js    ← 插件代码
└── icon.svg
```

## 钩子

插件通过**钩子**接入编译流程的各个阶段：转换内容、往模板里注入内容、部署、向外分发。清单里声明用到哪些钩子，青苔就在对应阶段回调你的代码。

```json
{
  "name": "my-plugin",
  "hooks": ["transform"]
}
```

## 插槽

**插槽**是模板里预留的位置（页头、页脚、边栏等）。插件可以往插槽注入 HTML，从而在不改主题的情况下给页面加入自定义元素。

## moss-api

插件运行时可以调用 **moss-api** 读取站点内容、访问配置、登记部署渠道。它是插件与青苔之间的接口。每个接口、工具和类型都记录在从源码生成的[完整 API 参考](https://github.com/Symbiosis-Lab/moss-api/tree/main/docs/api)中。
